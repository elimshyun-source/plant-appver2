# 화면 문구 (ui-text.md)

## 이 파일의 역할
화면 제목, 안내, 버튼처럼 **식물·증상·해결책이 아닌** 화면 글자를 모은다. 앱은 이 파일을 읽어서 쓰고, 코드에 문구를 직접 쓰지 않는다.
- 식물 이름은 plants.md, 증상·질문·답·"여기에 없어요"는 symptoms.md, 해결책 문장은 solutions.md에서 가져온다. 여기에는 적지 않는다.
- 쉬운 말 규칙(CLAUDE.md)을 따른다.

## 쓰는 법
- 표의 "키"는 앱이 문구를 찾는 이름이다. 키는 바꾸지 않고, 문구만 고친다.
- `**단어**`: 제목 안에서 포인트 초록으로 강조할 단어 하나 (design-system.md "글자").
- `{별명}`: 등록한 식물 별명. 뒤에 붙는 조사는 별명의 마지막 글자 받침에 맞춰 앱이 고른다. 문구에는 받침이 없을 때의 조사로 적는다(예: `{별명}는` → 폴폴이는 / 몬몬은, `{별명}를` → 스피를 / 올리브나무사랑을).
- `{식물 이름들}`: plants.md의 식물 이름을 쉼표로 이어 붙인 것.
- 표시: **[시안]**은 wireframes.png에서 옮긴 문구, **[제안]**은 시안에 없어서 새로 채운 문구다. [제안]은 내가 확인하기 전까지 바뀔 수 있다. **[확정]**은 내가 확인한 문구다.

|---|---|---|
| question.prev | 이전 질문 | [시안] |
| question.next | 다음 질문 | [시안] |
| question.emphasis.count | 몇 장 | [확정] ("노란 잎이 몇 장인가요?"에서 강조할 단어) |
| question.emphasis.soil | 흙 상태 | [시안] ("{별명}의 흙 상태는 어떤가요?"에서 강조할 단어) |

| question.light.title | 놓은 곳은 **햇빛**이 어떤가요? | [시안] (11/25: 등록에서 진단 질문으로 옮김) |
