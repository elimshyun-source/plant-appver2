# 증상별 해결책

## 이 파일의 역할
증상(그리고 추가 질문의 답)에 따라 보여줄 해결책을 적는다.
서비스는 **이 파일에 적힌 내용만** 해결책으로 보여준다.

## 쓰는 법
- 해결책 하나는 아래 틀을 그대로 쓴다.
- 이유는 가능성이 가장 높은 하나만 쓴다.
- 문장은 쉬운 말로 쓴다. (쉬운 말 사전은 overview.md에 있다.)
- 물 주는 간격, 양 같은 숫자는 확인된 것만 쓴다. 모르면 숫자를 빼고 쓴다.
- 모든 항목에는 상태를 표시한다. **[확인됨]**은 내가 확인한 것, **[초안]**은 아직 확인하지 않은 것이다.
- "확인 자료"는 내가 [확인됨]으로 바꿀 때 비교해 볼 자료다. 서비스 화면에는 보여주지 않는다.
- "식물별 안내"가 있는 해결책은, 사용자가 등록한 식물의 줄만 "해야 할 일" 아래에 덧붙여 보여준다. 근거는 plants.md의 "식물별 관리 정보"다. 식물별 안내가 "해야 할 일"과 다르면 식물별 안내를 따른다.
- "대상 식물"에 "로즈마리를 뺀"이라고 적힌 해결책은 로즈마리에게 보여주지 않는다. (로즈마리는 햇빛을 아주 좋아하고 물이 잘 빠져야 해서, 다른 식물과 안내가 다르다.)

## 작성 틀
```
## S-번호 증상 이름 (조건)
- 대상 증상: (symptoms.md의 증상 이름과 추가 질문의 답)
- 대상 식물: (모든 식물 / 로즈마리를 뺀 모든 식물 / 특정 식물)
- 지금 모습: (눈에 보이는 모습을 쉬운 말로)
- 이유: (가능성이 가장 높은 이유 하나)
- 해야 할 일: (바로 할 수 있는 행동)
- 식물별 안내: (식물마다 다르게 안내할 것이 있을 때만. 식물 이름: 안내)
- 확인 자료: (내가 비교해 볼 자료 링크. 식물별 안내의 근거는 plants.md의 "식물별 확인 자료")
- 상태: [초안] 또는 [확인됨]
```

## 해결책을 못 찾았을 때
증상과 답의 조합에 맞는 해결책이 아래에 없으면, 지어내지 말고 "이 증상은 아직 안내를 준비하지 못했어요"라고 보여준다.
- 예: 로즈마리 + 잎이 노래요 + 맨 아래 한두 장

## S-02 잎이 노래요 (여러 장, 흙이 말랐어요)
- 대상 증상: 잎이 노래요 + 여러 장 + 흙이 말랐어요
- 대상 식물: 모든 식물
- 지금 모습: 잎이 노랗게 변했고, 흙이 바싹 말라 있어요.
- 이유: 물이 부족해서일 가능성이 가장 높아요.
- 해야 할 일: 물을 천천히 나눠서 주세요. 화분 아래 구멍으로 물이 흘러나올 때까지 주세요. 그 뒤로는 손가락으로 눌러 보고 겉흙이 마르면 물을 주세요.
- 식물별 안내:
  - 스킨답서스: "구멍으로 물이 흘러나올 때까지" 문장은 보여주지 않아요. (자료 확인 못함)
  - 스파티필럼: 물을 준 뒤 받침에 고인 물은 비워주세요. 잎이 크게 처졌다면 물을 준 뒤 대부분 다시 일어나요.
  - 올리브나무: 그 뒤에는 흙이 많이 마른 다음에 주세요.
  - 몬스테라: 물을 준 뒤 받침에 고인 물은 비워주세요.
  - 로즈마리: 잎 위가 아니라 식물 밑동에 주세요.
- 확인 자료: [Epic Gardening - 스킨답서스 잎이 노랗게 될 때](https://merge.epicgardening.com/pothos-leaves-turning-yellow) / [농촌진흥청 - 봄철 실내 정원 관리(물 주는 시기)](https://rda.go.kr/webzine/2023/04/sub3-5.html) / [Epic Gardening - 로즈마리 문제](https://www.epicgardening.com/rosemary-dying/) / [클렘슨대 Extension - 실내 식물 물주기(구멍으로 나올 때까지, 받침 물 비우기)](https://hgic.clemson.edu/factsheet/indoor-plants-watering/) / [미주리 식물원 - 실내 식물 물주기](https://missouribotanicalgarden.org/gardens-gardening/your-garden/help-for-the-home-gardener/advice-tips-resources/visual-guides/how-to-water-indoor-plants) / 식물별: plants.md의 "식물별 확인 자료"

## S-03 잎이 노래요 (맨 아래 한두 장)
- 대상 증상: 잎이 노래요 + 맨 아래 한두 장
- 대상 식물: 로즈마리를 뺀 모든 식물
- 지금 모습: 맨 아래쪽 오래된 잎만 노랗게 변했어요.
- 이유: 오래된 잎이 자연스럽게 노래지는 걸 수 있어요.
- 해야 할 일: 노란 잎은 굳이 떼지 않아도 돼요. 살짝 당겨서 쉽게 떨어질 때만 떼 주세요. 새 잎이 잘 나오고 다른 잎이 멀쩡하면 걱정하지 않아도 돼요. 다른 잎도 노래지면 증상을 다시 골라주세요.
- 식물별 안내:
  - 스킨답서스: 나이 든 잎이 노래질 수 있어요. 잘라내고 싶다면 깨끗한 가위를 쓰세요.
  - 스파티필럼: 오래된 잎이 노래질 수 있지만, 물이 모자라거나 빛이 약해서일 수도 있어요. 떼고 싶다면 줄기 밑동에서 잘라주세요.
  - 올리브나무: 봄에 새 잎이 나면서 오래된 잎이 노래졌다 떨어질 수 있어요. 새 잎이 잘 나오는지 봐 주세요.
  - 몬스테라: 새 잎이 건강하면 가장 오래된 아래쪽 잎 한두 장이 노래지는 건 흔해요. 완전히 노래져서 쉽게 떨어질 때 떼어주세요.
- 확인 자료: [Lawn.com.au - 몬스테라 잎이 갈색이 될 때](https://lawn.com.au/?p=21838) / [Epic Gardening - 스킨답서스 잎이 노랗게 될 때](https://www.epicgardening.com/pothos-leaves-turning-yellow/) / 식물별: plants.md의 "식물별 확인 자료"(아래쪽 노란 잎)
- 상태: [확인됨]

## S-04 잎이 노래요 (여러 장, 흙이 보통이에요, 햇빛이 어두운 곳)
- 대상 증상: 잎이 노래요 + 여러 장 + 흙이 보통이에요 + 진단에서 고른 햇빛 정도가 "어두워요"
- 대상 식물: 로즈마리를 뺀 모든 식물
- 지금 모습: 잎이 여러 장 노랗게 변했어요.
- 이유: 햇빛이 모자라서일 가능성이 가장 높아요.
- 해야 할 일: 더 밝은 곳으로 옮겨주세요.
- 식물별 안내:
  - 스킨답서스, 스파티필럼, 몬스테라: 밝은 간접광이 좋아요. 강한 햇빛이 바로 닿으면 잎이 탈 수 있어요.
  - 올리브나무: 햇빛이 바로 닿아야 하는 식물이에요. 집에서 햇빛이 가장 잘 드는 창가(남향)로 옮겨주세요.
- 확인 자료: [Leon & George - 올리브나무 잎이 노랗게 될 때](https://www.leonandgeorge.com/pages/olive-trees-yellow-leaves) / [Bloomscape - 스킨답서스 잎이 노랗게 될 때](https://www.bloomscape.com/common-issue/why-are-the-leaves-of-my-pothos-turning-yellow) / 식물별: plants.md의 "식물별 확인 자료"(햇빛)

## S-11 잎이 노래요 (로즈마리, 여러 장, 흙이 보통이에요, 햇빛이 어두운 곳)
- 대상 증상: 잎이 노래요 + 여러 장 + 흙이 보통이에요 + 진단에서 고른 햇빛 정도가 "어두워요"
- 대상 식물: 로즈마리
- 지금 모습: 잎이 여러 장 노랗거나 연한 초록색으로 변했어요.
- 이유: 로즈마리는 햇빛을 아주 좋아하는데 햇빛이 모자랄 수 있어요.
- 해야 할 일: 집에서 햇빛이 가장 잘 드는 창가로 옮겨주세요.
- 확인 자료: [Epic Gardening - 로즈마리 문제](https://www.epicgardening.com/rosemary-dying/) / [펜실베이니아주립대 Extension - 로즈마리](https://extension.psu.edu/herb-garden-plants-rosemary) / [위스콘신대 Extension - 로즈마리](https://hort.extension.wisc.edu/articles/rosemary-rosemarinus-officinalis/) / [Rowe Organic - 로즈마리 잎이 노래질 때](https://roweorganic.com/rosemary-yellowing-leaves/)

## S-12 잎이 노래요 (여러 장, 흙이 보통이에요, 햇빛이 밝은 곳, 자리를 옮기거나 더 큰 화분으로 옮겨 심었어요)
- 대상 증상: 잎이 노래요 + 여러 장 + 흙이 보통이에요 + 진단에서 고른 햇빛 정도가 "밝아요/보통" + 최근 변화: 자리를 옮기거나 더 큰 화분으로 옮겨 심었어요
- 대상 식물: 로즈마리를 뺀 모든 식물
- 지금 모습: 잎이 여러 장 노랗게 변했어요. 최근에 자리를 옮기거나 더 큰 화분으로 옮겨 심었어요.
- 이유: 새 자리나 새 화분에 적응하는 중일 수 있어요.
- 해야 할 일: 자리를 자꾸 바꾸지 말고 한동안 지켜봐 주세요. 찬바람이 닿는 곳(창틈 등)은 피해주세요. 더 큰 화분으로 옮겨 심은 뒤에 오래된 잎 몇 장이 노래지는 건 흔하고, 보통 시간이 지나면서 나아져요. 노란 잎이 계속 늘어나면 증상을 다시 골라주세요.
- 식물별 안내:
  - 스킨답서스: 찬바람과 갑작스러운 온도 변화에 약해요. 더 큰 화분으로 옮겨 심었다면 한동안 비료는 주지 마세요.
  - 스파티필럼: 더 큰 화분으로 옮겨 심은 것, 창틈으로 들어오는 찬바람, 비료를 너무 많이 준 것도 노란 잎의 원인일 수 있어요.
  - 올리브나무: 자리를 옮기면 잎이 떨어질 수 있어요. 환경에 맞으면 다시 자라요.
  - 몬스테라: 더 큰 화분으로 옮겨 심은 뒤에는 오래된 아래쪽 잎이 노래질 수 있어요. 새 빛 환경에는 서서히 적응시켜 주세요.
- 확인 자료: [미주리 식물원 - 실내 식물 잎이 노래질 때(온도 변화, 장소 이동)](https://www.missouribotanicalgarden.org/gardens-gardening/your-garden/help-for-the-home-gardener/advice-tips-resources/gardening-help-faqs/question/516/why-are-the-leaves-on-my-indoor-plant-yellowing) / [Epic Gardening - 몬스테라 잎이 노랗게 될 때(분갈이 후, 찬 공기)](https://www.epicgardening.com/monstera-yellow-leaves/) / [Epic Gardening - 스파티필럼 문제(분갈이 직후, 찬바람)](https://www.epicgardening.com/peace-lily-problems/) / [일리노이대 Extension - 실내 식물 문제 해결(장소 이동 후 노래짐)](https://extension.illinois.edu/sites/default/files/troubleshooting_houseplants_0.pdf)
- 상태: [확인됨]

## S-13 잎이 노래요 (여러 장, 흙이 보통이에요, 햇빛이 밝은 곳, 비료를 줬어요)
- 대상 증상: 잎이 노래요 + 여러 장 + 흙이 보통이에요 + 진단에서 고른 햇빛 정도가 "밝아요/보통" + 최근 변화: 비료를 줬어요
- 대상 식물: 로즈마리를 뺀 모든 식물
- 지금 모습: 잎이 여러 장 노랗게 변했어요. 최근에 비료를 줬어요.
- 이유: 비료를 너무 많이 줘서일 수 있어요.
- 해야 할 일: 비료 주기를 멈춰주세요. 비료를 멈춘 채 새 잎이 어떻게 나는지 봐 주세요. 노란 잎이 계속 늘어나면 증상을 다시 골라주세요.
- 식물별 안내:
  - 스파티필럼: 비료를 많이 주면 잎이 노래질 수 있어요. 이유가 한 가지로 정해지지는 않아서 물 주기와 햇빛도 함께 봐 주세요.
  - 몬스테라: 비료의 염분이 흙에 쌓이면 뿌리와 잎이 상할 수 있어요.
- 확인 자료: [Epic Gardening - 몬스테라 잎이 노랗게 될 때(비료 과다)](https://www.epicgardening.com/monstera-yellow-leaves/) / [Epic Gardening - 스파티필럼 문제(비료 과다)](https://www.epicgardening.com/peace-lily-problems/)
- 상태: [확인됨]

## S-14 잎이 노래요 (여러 장, 흙이 보통이에요, 햇빛이 밝은 곳, 달라진 게 없어요)
- 대상 증상: 잎이 노래요 + 여러 장 + 흙이 보통이에요 + 진단에서 고른 햇빛 정도가 "밝아요/보통" + 최근 변화: 달라진 게 없어요
- 대상 식물: 로즈마리를 뺀 모든 식물

- 해야 할 일: 잎 뒷면을 살펴보세요. 흰 솜털 같은 것, 작은 점, 가느다란 거미줄이 보이면 벌레일 수 있어요. 벌레가 보이면 다른 식물과 떨어뜨려 놓고, 샤워기 같은 물줄기로 잎 앞뒤를 씻어내 주세요. 다시 생기면 같은 방법을 반복해 주세요.
